# Openline

This repository is based on the source code for **Openline**, an open-source
release of the Hotline Connect suite, including Hotline Client, Hotline Server,
and Hotline Tracker (old and new).

The source comes from the original Openline 1.9 source distribution. The
original source distribution's `LICENSE` file could not be recovered; however,
the [Hotline SourceForge project](https://sourceforge.net/projects/hotline/)
identifies the project as licensed under the GNU General Public License version
2.0 (GPLv2).
